# LIDA 前端快速启动指南

## 前提条件

确保已安装以下软件:
- Node.js 14+ (推荐 v16+)
- npm 或 yarn
- Python 3.10+ (后端服务)

## 快速开始

### 1. 安装依赖

```bash
cd frontend
npm install
```

如果下载速度慢，可以使用淘宝镜像:
```bash
npm config set registry https://registry.npmmirror.com
npm install
```

### 2. 启动后端服务

在新终端窗口中启动 LIDA 后端:

```bash
# 在项目根目录
cd C:\Users\Elvin\Desktop\GitHub\lida

# 初始化数据库 (首次运行)
python lida/init_db.py

# 启动后端服务
python -m lida.web.app
# 或者使用 uvicorn
uvicorn lida.web.app:app --host 0.0.0.0 --port 8000 --reload
```

后端将运行在 http://localhost:8000

### 3. 启动前端开发服务器

在另一个终端窗口:

```bash
cd frontend
npm run serve
```

前端将运行在 http://localhost:8080

### 4. 访问应用

打开浏览器访问: http://localhost:8080

## 常见问题

### Q: 前端无法连接后端?

**A**: 检查以下几点:
1. 确保后端服务正在运行 (http://localhost:8000)
2. 检查 vue.config.js 中的代理配置
3. 查看浏览器控制台的网络请求错误信息

### Q: 上传文件失败?

**A**: 
1. 检查文件大小是否超过限制 (10MB)
2. 确认文件格式是否正确 (CSV/Excel/JSON)
3. 查看后端日志获取详细错误信息

### Q: 图表无法显示?

**A**:
1. 检查是否安装了 Vega 相关依赖
2. 确认数据格式是否正确
3. 查看浏览器控制台是否有 JavaScript 错误

## 生产环境部署

### 构建生产版本

```bash
npm run build
```

构建产物将输出到 `dist/` 目录

### 使用 Nginx 部署

```nginx
server {
    listen 80;
    server_name your-domain.com;

    location / {
        root /path/to/frontend/dist;
        try_files $uri $uri/ /index.html;
    }

    location /api {
        proxy_pass http://localhost:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```
