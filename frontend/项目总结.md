## 🚀 快速启动

```bash
cd frontend
npm install
```

### 启动开发服务器
```bash
npm run serve
```
访问：http://localhost:8080

### 构建生产版本
```bash
npm run build
```

## 📖 使用说明

1. **首次使用**
   - 访问 http://localhost:8080/demo 查看演示
   - 点击"立即体验"进入登录页
   - 注册新账号或使用现有账号登录

2. **上传数据**
   - 登录后在主页上传 CSV/Excel/JSON 文件
   - 填写数据描述
   - 等待系统生成摘要

3. **生成可视化**
   - 在聊天列表中点击进入详情
   - 查看自动生成的可视化目标
   - 点击"生成可视化"按钮创建图表
   - 使用自然语言编辑优化图表
